# Test data provenance

`peptdeep_irt_peptides_predicted.csv` is copied unchanged from
[OpenMS commit d095891319ba904c5a8f6b117c83988fdfb4dc2c](https://github.com/OpenMS/OpenMS/blob/d095891319ba904c5a8f6b117c83988fdfb4dc2c/src/tests/class_tests/openms/data/peptdeep_irt_peptides_predicted.csv).
It contains independently computed raw and calibrated predictions for the 11
Biognosys iRT standards, used by `check_irt.py`. Keeping this small reference
here allows the regression to run without a separate OpenMS source checkout.
