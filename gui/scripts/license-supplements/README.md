These unmodified upstream notices fill omissions in published dependency packages.
`index.json` pins each affected package version, source URL and SHA-256.
The collector verifies every supplemental text before bundling it.

The objc2 family publishes a license declaration without the full MIT terms;
its exact upstream declaration is retained alongside the SPDX MIT text.
Selectors publishes MPL-2.0 source-file headers; the SPDX full terms accompany
the exact-version crate source URL in the generated inventory.
